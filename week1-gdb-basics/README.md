# Week 1: GDB User-Space Basics

Week 1 builds the core GDB workflow with ordinary C programs.

Labs:

- `lab01-breakpoints`: wrong result, breakpoints, stepping, printing.
- `lab02-stack-backtrace`: segfault, backtrace, stack frames, function arguments.
- `lab03-watchpoints`: unexpected state change, watchpoints, conditional debugging.

Run each lab from its own directory.
