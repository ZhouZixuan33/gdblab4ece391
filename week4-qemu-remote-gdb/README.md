# Week 4: QEMU and GDB Remote Debugging

Planned labs:

- `lab11-qemu-hello`: start a QEMU target paused for GDB.
- `lab12-remote-breakpoints`: set breakpoints by symbol and raw address.
- `lab13-registers-and-exceptions`: inspect exception-style failures.
- `lab14-mini-kernel-debug`: diagnose early boot hang, wrong entry, and reset-like behavior.

The QEMU labs stay lightweight and focus on debugging workflow rather than recreating a full operating system.
